# CV Semester 7 Experiment Submission

Computer Vision lab experiment implementations and submissions.

## Repository Structure

- `Experiment-1/`: Basic OpenCV operations (image reading, pixel manipulation, ROI, resizing, flipping, rotating, shape/text drawing).
- `Experiment-2/`: Salt & Pepper noise simulation and noise probability analysis (0.1 to 0.5).
- `Experiment-3/`: Spatial filtering evaluation (Median vs Mean filtering) with varying kernel sizes (3x3 to 11x11) and strides (1 to 4).
- `Experiment-4/`: Additive Gaussian noise simulation and 2D spatial Gaussian filtering evaluation across kernel sizes and strides.
- `Experiment-5/`: Sobel edge detection (gradient calculation in X and Y directions, edge magnitude, and OpenCV verification).
- `Experiment-6/`: Otsu's thresholding method (between-class variance maximization, manual thresholding, OpenCV verification, and parametric comparison).
- `Experiment-7/`: Gray-Level Co-occurrence Matrix (GLCM) texture feature extraction and multi-dimensional feature space analysis.
- `Experiment-8/`: Parametric line detection via Hough Transformation (Cartesian (m, c) vs. Polar (r, θ) parameter spaces and iterative weight peeling).
- `Data/`: Shared image assets.
